## 3. 默认假设（非阻塞）

| 假设 | 理由 | 影响 |
| --- | --- | --- |
| 角色权限暂不接入中台审批/资源授权 | 需求明确“审批仅记录状态变更” | 页面按钮按单据状态显隐，不做权限码校验 |
| 申请人/审批人使用 DTO/默认值，不取中台登录态 | 项目现有订单模块也未接用户上下文 | 便于本地与 UI 联调；后续可接 `req.userId` |
| 编辑/删除仅允许草稿状态 | 最小充分实现，避免已提交单据被篡改 | 已提交单据需先撤回再编辑 |
| 物理删除仅限草稿，子表随主表删除 | 与订单模块一致的删除语义 | 已提交/通过/驳回单据不可删除 |
| 并发控制用版本号字段 + 条件更新 | 项目现有 DAL 无内置乐观锁 | 冲突返回 409/90000206 |
