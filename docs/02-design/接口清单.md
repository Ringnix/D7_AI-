# 接口清单

统一前缀：`http://127.0.0.1:8081`；统一响应结构 `{ success, errorCode, msg, data }`；可选请求头 `X-Request-Id`。

| 编号 | 方法 | 路径 | 说明 | 关键参数 | 成功响应 |
| --- | --- | --- | --- | --- | --- |
| API-01 | GET | `/purchase-requests` | 分页查询 | `current`(1起)、`pageSize`、`requestNoLike`、`titleLike`、`status` | `Page<PurchaseRequestListVo>` |
| API-02 | GET | `/purchase-requests/{id}` | 详情（含明细） | id | `PurchaseRequestVo` |
| API-03 | POST | `/purchase-requests` | 新增（保存草稿） | `PurchaseRequestCreateDto` | 新单据 ID |
| API-04 | PUT | `/purchase-requests/{id}` | 修改（仅草稿） | `PurchaseRequestModifyDto`（含 version） | 空 |
| API-05 | DELETE | `/purchase-requests/{id}` | 删除（仅草稿） | id | 空 |
| API-06 | POST | `/purchase-requests/{id}/submit` | 提交 | `{ version }` | 空 |
| API-07 | POST | `/purchase-requests/{id}/cancel` | 取消 | `{ version, reason }` | 空 |
| API-08 | POST | `/purchase-requests/{id}/withdraw` | 撤回 | `{ version }` | 空 |
| API-09 | POST | `/purchase-requests/{id}/approve` | 审批通过 | `{ version, approverName?, opinion? }` | 空 |
| API-10 | POST | `/purchase-requests/{id}/reject` | 审批驳回 | `{ version, reason }` | 空 |

## 错误码

| 错误码 | HTTP | 说明 |
| --- | --- | --- |
| 00000000 | 200 | 成功 |
| 90000201 | 409 | 申请单号已存在 |
| 90000202 | 404 | 采购申请单不存在 |
| 90000203 | 409 | 当前状态不允许该操作 |
| 90000204 | 400 | 取消原因不能为空 |
| 90000205 | 400 | 驳回原因不能为空 |
| 90000206 | 409 | 版本冲突（乐观锁） |
| 框架校验码 00000002 | 400 | 参数校验失败（标题/明细等） |

## 分页字段约定

- 请求：`current` 从 1 开始，`pageSize` 默认 20、最大 100。
- 响应：`current`、`pageSize`、`total`、`totalPage`、`datas`。
- 与项目现有订单模块保持一致，不写 `page`/`size`。
