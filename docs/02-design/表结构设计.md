# 表结构设计

## 1. 主表 backend_demo_purchase_request

| 字段 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| id | BIGINT | 是 | - | 主键，DAL 雪花 ID |
| created_user_id | BIGINT | 是 | 0 | 创建用户 ID |
| created_user_name | VARCHAR(100) | 是 | '' | 创建用户名 |
| created_time | DATETIME | 是 | CURRENT_TIMESTAMP | 创建时间 |
| last_modified_user_id | BIGINT | 是 | 0 | 最后修改用户 ID |
| last_modified_user_name | VARCHAR(100) | 是 | '' | 最后修改用户名 |
| last_modified_time | DATETIME | 是 | CURRENT_TIMESTAMP | 最后修改时间 |
| tenant_id | BIGINT | 是 | 0 | 租户 ID |
| business_zone_id | BIGINT | 是 | 0 | 业务空间 ID |
| app_instance_id | BIGINT | 是 | 0 | 应用实例 ID |
| request_no | VARCHAR(32) | 是 | - | 申请单号，唯一 |
| title | VARCHAR(100) | 是 | - | 标题 |
| applicant_name | VARCHAR(100) | 是 | - | 申请人 |
| department | VARCHAR(100) | 是 | - | 申请部门 |
| total_amount | DECIMAL(14,2) | 是 | 0 | 申请总金额 |
| status | VARCHAR(32) | 是 | - | DRAFT/SUBMITTED/APPROVED/REJECTED/CANCELLED |
| remark | VARCHAR(500) | 否 | NULL | 备注 |
| version | INT | 是 | 0 | 乐观锁版本号 |
| cancel_reason | VARCHAR(500) | 否 | NULL | 取消原因 |
| cancelled_time | DATETIME | 否 | NULL | 取消时间 |
| approval_user_id | BIGINT | 否 | NULL | 审批用户 ID |
| approval_user_name | VARCHAR(100) | 否 | NULL | 审批人 |
| approval_time | DATETIME | 否 | NULL | 审批时间 |
| approval_opinion | VARCHAR(500) | 否 | NULL | 审批意见 / 驳回原因 |

约束与索引：

- 主键 `id`
- 唯一约束 `uk_backend_demo_purchase_request_no (request_no)`
- 索引 `idx_backend_demo_purchase_request_created (created_time, id)`
- 索引 `idx_backend_demo_purchase_request_status (status, created_time)`

## 2. 子表 backend_demo_purchase_request_item

| 字段 | 类型 | 必填 | 默认 | 说明 |
| --- | --- | --- | --- | --- |
| id | BIGINT | 是 | - | 主键，DAL 雪花 ID |
| request_id | BIGINT | 是 | - | 采购申请单 ID |
| item_name | VARCHAR(100) | 是 | - | 物品名称 |
| spec | VARCHAR(100) | 否 | NULL | 规格型号 |
| unit | VARCHAR(20) | 否 | NULL | 单位 |
| quantity | DECIMAL(12,2) | 是 | - | 数量 |
| unit_price | DECIMAL(12,2) | 是 | - | 单价 |
| amount | DECIMAL(14,2) | 是 | - | 金额（后端计算） |
| sort_no | INT | 是 | 0 | 排序号 |

索引：`idx_backend_demo_purchase_request_item_request (request_id, sort_no)`。
