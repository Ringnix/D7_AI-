## 联调过程

1. 启动后端，确认 8081 与 Liquibase 执行成功；
2. Vite 代理新增 `/api/purchase-requests`，重启 dev server；
3. mock 平台提供登录态所需接口，注入测试 Token；
4. 进入 `/#/purchase-request/list`，列表加载真实接口数据（5 条，来自接口测试数据）；
5. 校验列表状态/操作按钮、详情弹框、新增表单弹框、取消原因弹框；
6. 截图 4 张，记录浏览器 console error。
