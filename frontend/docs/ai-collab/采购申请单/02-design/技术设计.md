# 技术设计

## 1. 设计原则

- 复用现有 DDD 分层：api（接口/DTO/VO/枚举）→ context（实体/仓储/领域服务/应用服务）→ starter（Controller/异常处理）。
- 最小充分实现：不引入工作流引擎、不新增权限体系、不做导出/批量操作。
- 数据一致性：主子表同事务；状态流转先校验再条件更新。
- 并发：主表 `version` 乐观锁，SQL 条件更新，影响 0 行即冲突。
- 前端复用 CTable / useTable / CDynamicForm 风格，列表 + 弹框，保持与订单模块一致。

## 3. 状态机

| 当前状态 | 动作 | 目标状态 | 校验 |
| --- | --- | --- | --- |
| DRAFT | 提交 | SUBMITTED | 明细不能为空、版本一致 |
| SUBMITTED | 撤回 | DRAFT | 版本一致 |
| SUBMITTED | 审批通过 | APPROVED | 版本一致、记录审批人/时间/意见 |
| SUBMITTED | 审批驳回 | REJECTED | 驳回原因必填、版本一致 |
| DRAFT / SUBMITTED | 取消 | CANCELLED | 取消原因必填、版本一致 |
| DRAFT | 修改 | DRAFT | 版本一致、主子表同事务 |
| DRAFT | 删除 | - | 主子表同事务删除 |
| 其它 | 任意动作 | - | 90000203 当前状态不允许 |

## 4. 乐观锁

- 主表 `version INT NOT NULL DEFAULT 0`。
- 所有更新通过 `updatePurchaseRequest`：
  `update ... set version = version + 1 ... where id = ? and version = ?`
- 更新前先比对实体 version 与请求 version，给出 90000206；SQL 再兜底并发。
- 前端每次从列表/详情取得 version 并携带到动作接口。

## 5. 事务与一致性

- `createPurchaseRequest`：保存主表 → 保存明细；`@Transactional(rollbackFor = Exception.class)`。
- `modifyPurchaseRequest`：版本条件更新主表 → 删除旧明细 → 插入新明细。
- `deletePurchaseRequest`：删除明细 → 删除主表（仅草稿）。
- 所有原因/状态变更均在同一事务内完成。

## 6. 金额计算

- 明细金额 = quantity × unitPrice，`setScale(2, HALF_UP)`。
- 主表 totalAmount = 各明细金额之和，`setScale(2, HALF_UP)`。
- 金额由后端计算，前端只做展示与合计预览。

## 7. 异常与日志

- 业务异常：`BaseI18nException` + `BackendDemoErrorCode`（90000201~90000206）。
- HTTP 映射：201/206 → 409，202 → 404，其余 → 400。
- 应用服务记录 `requestId / operation / purchaseRequestId / result / elapsedMs`，失败记录 WARN，不打印敏感数据。

## 8. 前端设计

- 路由：`/purchase-request/list`，`src/router/purchase-request.ts`。
- 页面：列表（搜索 + CTable + 操作按钮）、新增/编辑弹框（主表 Form + 可编辑明细表）、详情弹框、动作弹框（取消/驳回/通过）。
- 操作按钮按状态渲染；删除红色；动作弹框原因必填。
- 服务层：`src/service/purchase-request/*`，错误码映射到页面提示。
- 国际化：`purchase-request.*` 中英文。
- 代理：Vite 新增 `/api/purchase-requests` → 服务 A 8081。

## 9. 关键取舍

| 取舍 | 选择 | 原因 |
| --- | --- | --- |
| 审批流引擎 | 不接入 | 需求明确仅记录状态 |
| 悲观锁 | 不用 | 单据冲突概率低，版本号更轻量 |
| 编辑范围 | 仅草稿 | 避免已提交数据被改动 |
| 删除方式 | 仅草稿物理删除 | 与订单模块一致，主子表事务删除 |
| 前端表单组件 | 主表 a-form + 明细 a-table | CDynamicForm 对动态明细支持有限，保持可维护 |
