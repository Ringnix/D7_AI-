## 代码部署/启动方式

### 后端

```powershell
cd backend-demo
mvn -DskipTests package
# 启动（本地 MySQL）
$env:SERVER_PORT='8081'; $env:DB_URL='jdbc:mysql://127.0.0.1:3306/java_simulation_project?...'
$env:DB_USERNAME='root'; $env:DB_PASSWORD='<本地密码>'; $env:NACOS_ENABLED='false'
java -jar backend-demo-server/target/backend-demo-server-0.0.1-SNAPSHOT.jar
```

Liquibase 会自动执行 `v1.3.0.xml` 建表。

### 前端

```powershell
cd cyberway-mp-frontend-template-release-1.23.0
yarn dev
```

- 访问 `http://localhost:3000/#/purchase-request/list`
- 开发代理：`/api/purchase-requests` → `127.0.0.1:8081`（vite.config.ts）
- 容器化部署需在 nginx 中补充 `/api/purchase-requests` 反代到后端地址（本次未改部署 nginx，待人工确认）。

## 敏感信息检查

- 未包含 `.env*`、`*.pem`、`*.key`、凭据、secrets、prod-exports、`*.log`、`.git`、`node_modules`、`target`、dist 构建产物。
- 测试数据均为虚拟名称/编号；未使用真实客户数据。
- 文档中的数据库/端口为本地实训环境信息。

## 复现步骤

1. 启动本地 MySQL，执行后端启动命令（Liquibase 建表）；
2. 按 `05-test/接口测试/seed.sql` 造数（唯一 INSERT）；
3. 运行 `05-test/接口测试/run-interface-tests.ps1`（需 PowerShell 5.1，脚本为 UTF-8 BOM）；
4. 启动前端 dev server，按 `07-ui/UI测试用例.md` 验证页面。
